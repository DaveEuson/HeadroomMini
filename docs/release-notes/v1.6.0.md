## Yoyu v1.6.0

**Headroom Mini is now Yoyu.** Same board, same product, new name — and a new
mascot to go with it. Everything saved on your board survives the upgrade, but
a few addresses change, so read *Upgrading* before you go looking for the old
ones.

### The name

**Yoyu よゆう** — *yoyū*, Japanese for "room to spare", which is the thing this
device measures. The old name collided with a well-known Claude-token project
of the same name; that was reason enough to move.

What changes with it:

| | Before | Now |
|---|---|---|
| Setup page | `daveeuson.github.io/HeadroomMini/` | **`daveeuson.github.io/Yoyu/`** |
| Board address | `headroom.local` | **`yoyu.local`** |
| Setup hotspot | `Headroom-Setup` | **`Yoyu-Setup`** (password `yoyu`) |
| Companion download | `HeadroomCompanion-*` | **`YoyuCompanion-*`** |

**The old setup-page URL now 404s.** GitHub redirects a renamed repository but
not its Pages site, so a bookmark to the old flasher address is dead — update
it. Links to the repository and to release downloads *do* redirect, so boards
already in the field keep updating normally.

### A kitsune, whose tails count your headroom

The mascot was a blue robot called Sprocket. It is now a red kitsune, and the
tails are not decoration: a kitsune gains tails as it gains power, so the fox
carries the same number the meters print — **three tails** above 60% headroom,
**two** down to 25%, **one** below that. Readable across a desk without reading
a number.

It keeps all five moods — waiting, on a roll, running low, out of tokens,
resting — now on a fox that has a body, ears that carry the mood colour, and a
face that reads at 2 inches.

The tail count is also a second, non-colour carrier of "how much is left",
alongside the meters' fill length and printed percentage.

### Fixes

- **The mascot and the line beneath it could contradict each other.** The fox
  read your 5-hour window while the stat line printed whichever window was
  fullest. So the board could show "on a roll!" over three tails with
  "Weekly 96% used" directly underneath — and throw up the reset Timer for a
  window the fox looked cheerful about. Mood, tails and the stat line now all
  read the window with the *least* headroom: the one that actually stops you
  working. (The History graph deliberately stays on the 5-hour window — it
  would jump between series otherwise.)
- **Upgrading could leave two companions starting at login on Windows.** The
  autostart entry was renamed `HeadroomCompanion.bat` → `YoyuCompanion.bat`,
  but the uninstaller only knew the new name, so the old entry stayed in your
  Startup folder permanently and `--uninstall` could not remove it. The
  single-instance lock made that harmless rather than absent; it is now
  actually cleaned up. macOS and Linux were never affected.
- **The mascot overflowed panels larger than this board's.** Groundwork for a
  second supported board turned up that the sprite was sized off the bitmap-font
  step, which stopped matching the sprite grid when the mascot grew. On a
  410×502 panel that drew 468px of fox onto 410px of glass. It is now fitted to
  the glass on both axes. No visible change on this board — verified pixel-identical.
- **Party confetti was positioned in raw pixels**, so on a larger panel it
  bunched into the top-left corner and could clip the caption.

### Upgrading

**Over the air from `/update`, or re-flash from the setup page.** Both keep your
Wi-Fi, your Claude login and your settings — the board's saved-settings area was
deliberately *not* renamed, precisely so this upgrade wouldn't wipe it. A fresh
install from the flasher still starts clean and will ask you to pair again.

Two things to expect afterwards:

- **The board answers to `yoyu.local` now.** If you had `headroom.local`
  bookmarked, update it. The companion finds the board on either name, so
  push mode and `--pair` keep working with no action from you.
- **The setup hotspot is `Yoyu-Setup`** if you ever factory-reset.

The companion is worth updating too, for the Windows autostart fix above, but
an old companion still feeds a new board.
