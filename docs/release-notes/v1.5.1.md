## HeadroomMini v1.5.1

A first-run fix. If you've flashed a board from the setup page, this is the one
to be on.

### Headroom Mini (ESP32-S3)

- **"Visit Device" now opens the board.** After the browser flasher sets up
  Wi-Fi, its **Visit Device** button opens the address the board hands back over
  Improv — and that address was missing its port. Port 80 is the setup portal,
  which only exists before the board joins your network; once it's on Wi-Fi it
  serves on `:8080`. So the first thing you clicked after setting the board up
  went to a port with nothing listening on it.
- **The landing-page footer carries the port too.** It printed the bare IP and
  `headroom.local`, both of which land on that same closed port when copied
  into a browser. Both now read `:8080`.

Nothing else changed — same screens, same behaviour as v1.5.0.

### Upgrading

Over-the-air from `/update`, or re-flash from the setup page. Both keep your
Wi-Fi and pairing; a fresh install from the flasher does not, and will ask you
to pair again.
